OUTBOUND DELIVERY OFF BY DEFAULT

SIEM & SOAR integrations

Checking local configuration

Delivery is off by default. You can send redacted security events to a signed HTTPS JSON webhook, an RFC 5424 Syslog TLS receiver, or an OTLP/HTTP JSON logs endpoint. Request bodies, images, credentials and raw camera data are excluded. Destinations must use a public DNS name; HTTPS uses port 443 and Syslog TLS uses port 6514. VAOS validates receiver certificates and pins the resolved public address for each connection. OTLP uses the OpenTelemetry Logs JSON encoding; protocol support does not certify compatibility with any particular SIEM vendor.

The delivery queue is capped at 50,000 rows overall and 5,000 pending per destination. If full, VAOS keeps the local security event but skips its external send and counts it as dropped. Terminal delivery history is retained for up to 90 days. Removing a destination clears its endpoint and credential reference while preserving local event history.

When editing, re-enter the complete receiver URL. VAOS does not reveal stored URL paths or credential names. Leave the credential field empty to keep its current environment-variable reference when the delivery type is unchanged.

No external destination is required to use VAOS. Enter environment-variable names only; never paste secret values here.
