COMMUNITY / PORTABLE CONFIGURATION

VAOS project bundles

Share a small VAOS setup with another local installation. Bundles carry approved engine settings and names of local datasets and models so another person can see what the project expects.

Privacy by design. A bundle contains configuration only. It excludes passwords, API tokens, camera and tunnel links, face profiles, review images, model weights, dataset files and executable content. Dataset/model names are references, not included files. Importing only saves the bundle; applying settings is a separate step.

Export this VAOS setup

Download a portable configuration bundle of the current engine settings and names of registered datasets and models.

Export does not include model weights or image data. Check the contents before sharing it.

Review and import a bundle

VAOS checks the file and shows what it contains. The first step is preview-only and makes no changes.

Saved project bundles

Saved bundles stay on this VAOS machine under its data folder. Removing a bundle does not remove any datasets or models it references.
