# VAOS documentation

VAOS was originally created by Prateek Dubey and is developed with contributions from the open-source community.

See [creator and community credits](CREDITS.md) for the creator's role and profile links, or open the in-app **About VAOS** page. VAOS is an Apache 2.0 open-source project. Community contributions are welcome; see the [contribution guide](../CONTRIBUTING.md). Keep existing project and third-party notices when reusing the code or assets.
