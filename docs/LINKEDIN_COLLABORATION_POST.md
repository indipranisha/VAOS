# LinkedIn collaboration post draft

I’m building VAOS (Video Analytics Operating System), a local-first, open-source video analytics application for camera workflows, object detection and tracking, reviewed samples, custom model training, documented APIs, and optional AI-agent control through MCP.

The VAOS 1.1.0 candidate brings together the API Explorer, tracking and event rules, hardware intelligence, MCP controls, project bundles, and observability. It is still a release candidate: the AI Model Arena and Ready-to-Run Vision Applications are deferred, and real-device GPU/camera, production restore and broader usability validation remain open. The project’s readiness report explains what has and has not been tested.

I’ve published a project white paper covering the architecture, workflows, security boundaries, hardware/OS limits, test evidence and contribution path:

VAOS was originally created by Prateek Dubey and is developed with contributions from the open-source community. If you work on computer vision, local-first software, accessibility, hardware support, testing, security or documentation, contributions and thoughtful review are welcome. Start with the contribution guide and please keep security reports private through the repository’s responsible disclosure path.

The source is Apache-2.0 licensed. Dataset, pretrained-model and dependency licenses remain separate and should be reviewed independently.
